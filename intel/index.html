📧 Email Header Analyzer

💡 How to save emails for upload:

  • Gmail: Open email → ⋮ (three dots) → "Download message" (saves as .eml)
  • Outlook:
    • Best: File → Save As → "HTML" (NOT "Web Page, Filtered") - saves single .html file
    • Alternative: File → Properties → Copy "Internet Headers" → Paste in tool
  • Apple Mail: File → Save As → Format: "Raw Message Source" (saves as .eml)

✅ Supported: .eml, .html, .htm, .txt (single file)

⚠️ NOT Supported: .msg files or multi-file HTML exports
